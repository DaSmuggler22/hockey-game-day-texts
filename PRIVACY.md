# Privacy

This is a personal, non-commercial project run by one person.

- The only information used is the mobile numbers of the owner and a few
  people the owner knows personally, each of whom asked to be added.
- Those numbers are stored as an encrypted GitHub secret. They are not in this
  repository and are never written to logs.
- Numbers are used only to send game-day reminder texts through Twilio. They
  are never shared, sold, or used for marketing.
- Anyone can reply `STOP` to stop the texts, or ask the owner to remove their
  number entirely.
